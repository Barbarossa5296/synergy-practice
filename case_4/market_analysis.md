# Анализ информационных систем, построенных по архитектуре WEB-приложений

## Введение

Сейчас многие программы работают не как обычные приложения на компьютере, а через браузер. Пользователь открывает сайт, вводит логин и получает доступ к нужным функциям. При этом основная обработка данных происходит на сервере, а информация хранится в базе данных.

Такие системы называются WEB-приложениями.

Их главное удобство заключается в том, что программу не нужно отдельно устанавливать на каждый компьютер. Сотрудник может открыть её через браузер и работать с данными компании.

Для анализа я выбрал несколько систем, которые могут использоваться в туристической компании, гостинице или санатории:

- TravelLine;
- amoCRM;
- Битрикс24;
- 1С:Фреш.

Эти системы решают разные задачи: бронирование, работу с клиентами, организацию работы сотрудников и ведение учёта.

## Общие возможности WEB-приложений

WEB-приложения имеют несколько важных преимуществ.

Во-первых, сотрудники могут работать с системой с разных компьютеров. Например, менеджер может открыть программу в офисе, а руководитель — со своего ноутбука.

Во-вторых, данные хранятся в одном месте. Если один сотрудник изменил информацию о клиенте или бронировании, другие сотрудники тоже увидят эти изменения.

В-третьих, обновление программы обычно происходит на сервере. Пользователям не нужно вручную устанавливать новую версию.

Также WEB-приложения удобно связывать с другими сервисами:

- электронной почтой;
- телефонией;
- формами на сайте;
- платёжными системами;
- бухгалтерскими программами;
- мессенджерами.

При этом есть и недостатки. Работа системы зависит от интернета и доступности сервера. Кроме того, необходимо защищать данные пользователей и настраивать права доступа для сотрудников.

## TravelLine

### Что это за система

TravelLine — это система для гостиниц, санаториев, баз отдыха и других объектов размещения.

Она помогает работать с бронированиями, номерами, ценами и разными каналами продаж.

### Основные возможности

С помощью TravelLine можно:

- принимать бронирования с сайта;
- показывать гостям свободные номера;
- управлять стоимостью проживания;
- работать с разными тарифами;
- принимать оплату;
- передавать номера на сайты бронирования;
- следить за загрузкой гостиницы;
- получать отчёты;
- хранить сведения о гостях.

Одной из полезных функций является синхронизация свободных номеров на разных площадках. Это помогает избежать ситуации, когда один и тот же номер одновременно продали нескольким гостям.

### Преимущества

Главное преимущество TravelLine в том, что система создана именно для гостиничного бизнеса.

В ней уже есть необходимые функции для работы с номерами, тарифами и бронированиями. Поэтому её не нужно полностью настраивать с нуля.

Также сотрудники могут работать через браузер, а данные о бронированиях хранятся в одной системе.

### Недостатки

TravelLine решает в основном задачи, связанные с размещением и продажей номеров.

Она не заменяет полноценную бухгалтерскую программу и не подходит для всех внутренних процессов компании.

Некоторые возможности могут подключаться отдельно, из-за чего стоимость системы увеличивается.

### Использование в компании

В гостинице или санатории TravelLine можно использовать для:

- приёма бронирований;
- управления номерным фондом;
- контроля свободных мест;
- работы с тарифами;
- приёма оплаты;
- анализа загрузки;
- работы с сайтами бронирования.

Для объекта размещения это одна из самых подходящих систем из рассмотренных.

## amoCRM

### Что это за система

amoCRM — это система для работы с клиентами и продажами.

Основная часть программы — воронка продаж. В ней видно, на каком этапе находится каждая заявка.

Например, заявка может проходить следующие этапы:

1. клиент оставил обращение;
2. менеджер связался с клиентом;
3. клиенту отправили предложение;
4. клиент согласился;
5. была произведена оплата.

### Основные возможности

amoCRM позволяет:

- создавать карточки клиентов;
- сохранять контакты;
- вести сделки;
- ставить задачи менеджерам;
- хранить историю звонков и сообщений;
- подключать электронную почту;
- получать заявки с сайта;
- подключать телефонию и мессенджеры;
- создавать автоматические напоминания;
- смотреть отчёты по продажам.

Менеджер может открыть карточку клиента и увидеть, когда с ним связывались, что ему предлагали и на каком этапе находится сделка.

### Преимущества

Система достаточно понятна для отдела продаж.

Все заявки находятся в одном месте, поэтому они реже теряются. Руководитель может видеть работу менеджеров и контролировать просроченные задачи.

Также удобно, что обращения из разных каналов могут попадать в одну систему.

### Недостатки

amoCRM в первую очередь предназначена для продаж.

Она не управляет номерным фондом гостиницы, не ведёт бухгалтерию и не заменяет программу для расчёта зарплаты.

Для некоторых функций нужно подключать дополнительные сервисы и виджеты.

### Использование в компании

В туристической компании amoCRM можно использовать для:

- обработки заявок на туры;
- хранения контактов клиентов;
- контроля звонков;
- ведения переписки;
- постановки задач менеджерам;
- сопровождения клиента до оплаты;
- повторных продаж;
- работы с корпоративными клиентами.

Для гостиницы система может быть полезна в отделе продаж, особенно при работе с организациями, группами и туристическими агентствами.

## Битрикс24

### Что это за система

Битрикс24 — это более широкая система для управления работой компании.

Она включает не только CRM, но и задачи, проекты, внутреннее общение, документы и календарь.

### Основные возможности

В Битрикс24 можно:

- вести клиентов и сделки;
- ставить задачи;
- создавать проекты;
- назначать ответственных;
- хранить документы;
- общаться во внутреннем чате;
- проводить видеозвонки;
- вести календарь;
- подключать телефонию;
- создавать формы для сайта;
- автоматизировать некоторые действия;
- настраивать права доступа;
- смотреть отчёты.

Например, после поступления новой заявки система может автоматически создать сделку и поставить задачу менеджеру связаться с клиентом.

### Преимущества

Главное преимущество Битрикс24 — большое количество функций в одном месте.

Сотрудники могут работать с клиентами, задачами и документами, не переключаясь между большим количеством программ.

Система подходит не только для отдела продаж, но и для других подразделений компании.

### Недостатки

Из-за большого количества функций система может показаться сложной.

Перед началом работы необходимо настроить этапы сделок, права сотрудников, задачи и автоматические действия.

Если выполнить настройку неудачно, в системе может появиться много лишних уведомлений и полей.

### Использование в компании

В туристической компании Битрикс24 можно использовать для:

- ведения заявок;
- контроля менеджеров;
- работы с клиентами;
- постановки внутренних задач;
- хранения документов;
- согласования договоров;
- ведения календаря;
- общения между сотрудниками;
- контроля выполнения проектов.

Эта система подойдёт компании, которой требуется не только CRM, но и единое рабочее пространство для сотрудников.

## 1С:Фреш

### Что это за система

1С:Фреш — это сервис, который позволяет работать с программами 1С через интернет.

Пользователь открывает приложение через браузер и получает доступ к бухгалтерии, финансам, кадрам, продажам и другим разделам.

### Основные возможности

В зависимости от выбранной программы в 1С:Фреш можно:

- вести бухгалтерский учёт;
- учитывать доходы и расходы;
- формировать отчётность;
- работать с продажами и закупками;
- вести складской учёт;
- рассчитывать заработную плату;
- вести кадровый учёт;
- создавать счета и акты;
- контролировать расчёты с клиентами;
- получать финансовые отчёты.

### Преимущества

Главное преимущество состоит в том, что компании не обязательно устанавливать и самостоятельно обслуживать сервер 1С.

Обновления выполняются централизованно, а сотрудники могут работать через интернет.

Система хорошо подходит для бухгалтерии и финансового учёта.

### Недостатки

1С:Фреш не предназначена специально для гостиничного бронирования.

Она не управляет свободными номерами и не заменяет такие системы, как TravelLine.

Для обмена данными с другими программами может потребоваться настройка интеграции.

### Использование в компании

В туристической компании 1С:Фреш можно использовать для:

- бухгалтерского учёта;
- расчёта заработной платы;
- кадрового учёта;
- подготовки отчётности;
- учёта расходов;
- работы с поставщиками;
- создания счетов и актов;
- контроля финансов компании.

## Сравнение систем

| Система | Для чего подходит лучше всего | Плюсы | Минусы |
|---|---|---|---|
| TravelLine | Бронирования и управление объектом размещения | Создана специально для гостиниц и санаториев | Не заменяет бухгалтерию и CRM |
| amoCRM | Работа отдела продаж | Понятная воронка и карточки клиентов | Мало функций для внутренних процессов компании |
| Битрикс24 | Управление продажами, задачами и сотрудниками | Много функций в одной системе | Требуется настройка и обучение |
| 1С:Фреш | Бухгалтерия, финансы и кадры | Хорошо подходит для учёта и отчётности | Не предназначена для бронирования |

## Как эти системы можно использовать вместе

На мой взгляд, одной системы может быть недостаточно для полной автоматизации туристической компании.

Например, гостиница может использовать следующую схему:

1. TravelLine — для номеров, тарифов и бронирований.
2. amoCRM или Битрикс24 — для работы менеджеров с клиентами.
3. 1С:Фреш — для бухгалтерии, зарплаты и финансового учёта.

При этом между программами желательно настроить обмен данными, чтобы сотрудникам не приходилось вручную переносить одну и ту же информацию.

Для небольшой компании можно использовать меньше систем. Например, CRM для работы с клиентами и 1С для учёта.

Для крупной гостиницы или санатория уже потребуется отдельная система бронирования, CRM и бухгалтерская программа.

## Связь с разработанным приложением

Приложение, созданное в рамках кейса № 4, тоже построено по архитектуре WEB-приложения.

В нём:

- браузер используется для просмотра страницы;
- Flask принимает запрос пользователя;
- Python выполняет обработку;
- MySQL хранит сведения о туристических путёвках;
- HTML-шаблон выводит данные в виде таблицы.

Разработанная программа намного проще рассмотренных коммерческих систем. Она не позволяет создавать бронирования или изменять данные через браузер.

При этом она показывает основной принцип работы WEB-приложения: пользователь отправляет запрос, сервер получает данные из базы и возвращает готовую страницу.

## Заключение

В ходе анализа я рассмотрел четыре WEB-системы, которые можно использовать в туристической компании.

TravelLine подходит для гостиниц и санаториев, потому что работает с номерами и бронированиями.

amoCRM удобна для отдела продаж и контроля заявок клиентов.

Битрикс24 подходит для более широкой организации работы компании, включая задачи, документы и общение сотрудников.

1С:Фреш можно использовать для бухгалтерского, кадрового и финансового учёта.

WEB-приложения удобны тем, что работают через браузер, позволяют хранить данные в одном месте и обеспечивают совместную работу сотрудников.

Главными недостатками являются зависимость от интернета, необходимость защищать данные и затраты на настройку и обслуживание системы.
