# Кейс-задача № 5. Анализ программы из кейса № 2

## Выбор программы

Для пятого кейса я выбрал программу из кейса № 2.

В ней требовалось показать работу базового и производного классов.

[Исходный код программы](../case_2/case_2.py)

Программа содержит два класса:

- `DataProcessor` — базовый класс;
- `NumberProcessor` — производный класс.

Базовый класс хранит список данных, выводит его и показывает количество элементов.

Производный класс наследует базовый класс, но по-другому выполняет метод `process()`. Он рассчитывает сумму и среднее значение элементов. Также в нём есть отдельный метод для поиска минимального и максимального числа.

В основной части программы создаются объекты обоих классов. После этого для них вызываются одинаковые методы. Так в программе показана работа наследования и полиморфизма.

## 1. Функциональность

Программа выполняет основное задание.

В ней показаны:

- базовый класс;
- производный класс;
- наследование;
- переопределение метода;
- отдельный метод производного класса;
- свойство для работы с данными;
- обработка ошибки;
- полиморфизм.

Для объекта `DataProcessor` программа выводит список и количество элементов.

Для объекта `NumberProcessor` она выводит:

- список;
- сумму;
- среднее значение;
- минимальное число;
- максимальное число.

Для списка:

```text
[5, -2, 8, 4]
```

результат получается таким:

```text
Сумма элементов: 15
Среднее значение: 3.75
Минимальный элемент: -2
Максимальный элемент: 8
```

Также программа не разрешает создать объект с пустым списком.

При этом она не проверяет, что внутри списка находятся именно числа. Например, если передать строки, ошибка появится уже во время вычислений.

Основная задача выполнена, но проверку данных можно улучшить.

## 2. Производительность

Программа выполняет простые операции:

- копирует список;
- считает сумму;
- ищет минимальное значение;
- ищет максимальное значение;
- считает количество элементов.

Скорость работы зависит от размера списка. Чем больше элементов, тем больше времени потребуется на обработку.

Для обычных небольших списков разницы пользователь не заметит.

В программе свойство `data` возвращает копию списка. Это сделано для защиты внутренних данных объекта. Но при работе с очень большими списками создание копий может занимать дополнительное время и память.

Для данной учебной задачи это не является серьёзной проблемой, поэтому производительности программы достаточно.

## 3. Удобство использования

Результаты выводятся понятно и на русском языке.

Пользователь видит:

- название класса;
- исходные данные;
- результаты обработки;
- сообщение об ошибке.

Например, для пустого списка выводится понятное сообщение:

```text
Ошибка: Список данных не должен быть пустым.
```

Основной недостаток заключается в том, что списки заранее записаны в коде:

```python
DataProcessor([10, 20, 30])
NumberProcessor([5, -2, 8, 4])
```

Пользователь не может ввести собственные числа через консоль.

Чтобы проверить другой список, нужно менять исходный код.

Результат понятен, но взаимодействие с пользователем почти отсутствует.

## 4. Безопасность

Программа не работает с интернетом, файлами, базой данных и персональными данными. Поэтому серьёзных рисков безопасности в ней нет.

Внутренний список хранится в переменной:

```python
self.__data
```

Двойное подчёркивание показывает, что эта переменная должна использоваться только внутри класса.

Также программа создаёт копию списка. Поэтому изменение внешнего списка не должно напрямую изменить данные внутри объекта.

При этом проверяется только то, что список не пустой.

Не проверяются:

- тип самого значения;
- тип каждого элемента;
- наличие строк;
- наличие других неподходящих объектов.

Для учебной программы безопасность достаточная, но входные данные проверяются не полностью.

## 5. Масштабируемость

Программу можно расширять с помощью новых производных классов.

Например, можно добавить:

- класс для сортировки чисел;
- класс для поиска только положительных чисел;
- класс для вычисления дополнительных статистических показателей;
- класс для работы с вещественными числами.

Все такие классы могут наследоваться от `DataProcessor`.

Их можно будет добавить в общий список объектов, после чего основной цикл продолжит работать.

Это является плюсом выбранной структуры.

Недостаток состоит в том, что методы сразу выводят результат через `print()`.

Если позже понадобится использовать классы в WEB-приложении или графическом интерфейсе, методы лучше сделать так, чтобы они возвращали значения, а вывод выполнять отдельно, а не печатать их самостоятельно.

Классы можно расширять, но вычисления слишком сильно связаны с консольным выводом.

## 6. Сопровождаемость

Код небольшой, поэтому его легко прочитать целиком.

Плюсы:

- понятные названия классов;
- понятные названия методов;
- программа разделена на классы и основную функцию;
- используются аннотации типов;
- запуск программы находится в `main()`;
- нет лишних сложных конструкций.

Минусы:

- нет комментариев с описанием классов;
- нет отдельной инструкции по запуску;
- нет отдельного файла с тестами;
- вся программа находится в одном файле.

Для текущего размера программы это нормально.

Если проект станет больше, лучше разделить его на несколько файлов.

Сейчас код легко поддерживать, но при расширении потребуется более удобная структура.

## 7. Переносимость

Программа написана на Python и не использует сторонние библиотеки.

Для запуска нужен только установленный Python.

Она может работать в:

- Windows;
- Linux;
- macOS.

В коде нет путей к конкретным папкам и нет команд, которые работают только в одной операционной системе.

Запустить программу можно командой:

```bash
python case_2/case_2.py
```

На некоторых системах используется команда:

```bash
python3 case_2/case_2.py
```

Переносимость программы высокая.

## 8. Качество кода

Код написан достаточно понятно.

Положительные стороны:

- используются классы;
- показано наследование;
- показано переопределение метода;
- есть полиморфизм;
- есть свойство `data`;
- есть обработка исключения;
- используются аннотации типов;
- методы имеют понятные названия.

Программа не перегружена и соответствует учебной задаче.

При этом есть несколько моментов, которые можно улучшить:

1. Методы только печатают результат и ничего не возвращают.
2. Нет проверки элементов списка.
3. Нет описания классов и методов.
4. Нет автоматических тестов.
5. Пользователь не может вводить собственные данные.

Качество кода хорошее для небольшой учебной программы, но есть возможности для улучшения.

## 9. Тестирование

В задании программа названа тестовой. В данном случае это означает, что она показывает работу классов на примерах.

Это не полноценные автоматические тесты.

Сейчас программа проверяется на двух списках:

```text
[10, 20, 30]
[5, -2, 8, 4]
```

На этих данных видно, что методы работают правильно.

Также предусмотрена ошибка для пустого списка.

Но отдельно не проверялись:

- список из одного числа;
- список только из отрицательных чисел;
- список с нулём;
- список с одинаковыми числами;
- список с вещественными числами;
- список со строками;
- очень большой список.

В программе нет тестов, которые автоматически сравнивают полученный результат с ожидаемым.

Демонстрация работы есть, но автоматическое тестирование отсутствует.

## Найденные недостатки

В результате анализа я выделил следующие проблемы:

| Проблема | К чему может привести |
|---|---|
| Нет автоматических тестов | После изменения кода можно не заметить ошибку |
| Нет проверки типов | Программа может завершиться с ошибкой на неподходящих данных |
| Данные записаны прямо в коде | Пользователь не может ввести свои числа |
| Методы используют `print()` | Результаты сложно использовать в другом интерфейсе |
| Нет описания классов | Другому человеку потребуется больше времени, чтобы разобраться |
| Вся программа в одном файле | При расширении код станет сложнее поддерживать |

## Предлагаемые улучшения

### Добавить проверку элементов

При передаче списка можно проверить, что все элементы являются числами:

```python
if not all(isinstance(item, (int, float)) for item in value):
    raise TypeError("Все элементы списка должны быть числами.")
```

Тогда ошибка будет обнаружена сразу.

### Добавить ввод пользователя

Можно разрешить пользователю вводить числа через пробел:

```python
numbers = list(
    map(
        int,
        input("Введите числа через пробел: ").split()
    )
)
```

После этого список передаётся в `NumberProcessor`.

### Возвращать результаты из методов

Вместо того чтобы сразу выводить сумму и среднее значение, метод может их возвращать:

```python
def process(self):
    data = self.data
    total = sum(data)
    average = total / len(data)
    return total, average
```

Тогда результат можно будет использовать не только в консоли, но и в другом приложении.

### Добавить автоматические тесты

Для проверки можно использовать стандартный модуль `unittest`.

Стоит проверить:

- обычный список;
- пустой список;
- одно число;
- отрицательные числа;
- неправильные типы;
- правильность суммы;
- правильность среднего;
- правильность минимума и максимума.

### Добавить описание классов

Например:

```python
class DataProcessor:
    """Базовый класс для хранения и обработки списка данных."""
```

Так назначение класса будет понятно сразу.

### Разделить файлы при расширении программы

Если программа станет больше, можно использовать такую структуру:

```text
case_2/
├── processors.py
├── main.py
├── test_processors.py
└── README.md
```

В одном файле будут классы, в другом запуск программы, а в третьем тесты.

Для текущей версии это необязательно, но в дальнейшем такая структура будет удобнее.

## Заключение

Программа из кейса № 2 выполняет поставленную задачу.

Она показывает:

- наследование;
- работу базового и производного классов;
- переопределение методов;
- полиморфизм;
- инкапсуляцию.

Код небольшой и понятный. Он не требует сторонних библиотек и может запускаться на разных операционных системах.

Эти проблемы можно решить без полной переделки программы. Для этого достаточно добавить проверку элементов, ввод чисел, возврат результатов из методов и отдельные тесты.
